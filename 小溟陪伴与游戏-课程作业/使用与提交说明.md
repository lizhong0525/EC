# 小溟陪伴与游戏 · 网页设计课程作业

## 运行

1. 打开 `stages/01-html/index.html`，阅读角色介绍、对话示例和使用指南。
2. 打开 `stages/02-css/index.html`，在桌面或窄窗口浏览两款游戏的玩法。
3. 打开 `stages/03-js/index.html`，离线完成一步将死的棋局。
4. 运行 `site/启动小溟.cmd`，打开完整网站。需要 Python 3.10 或更新版本，象棋库已随包附带。关闭启动窗口即可结束服务。

完整网站在本机提供对话、国际象棋及四人「谁是卧底」。首页可检查 DeepSeek 配置并授权联网，也可直接体验标有「本地」的模式。使用说明和素材署名随源码附上。

## 查阅和提交

| 作业 | 主要交互 | 交付文件名后缀 |
| --- | --- | --- |
| HTML | 首页和指南双向定位 | 静态网页 |
| CSS | 选取游戏、定位规则、响应式布局 | CSS排版 |
| JavaScript | 合法落子、胜负反馈、重开 | JS交互 |
| 网站设计 | 多轮对话、两款游戏、刷新续局 | 网站设计 |

`prompts` 保存下发的任务书，`evidence` 保存初稿或定位问题的源码、运行截图和调试记录，`reports` 保存可编辑 Word 报告及 PDF。四个可分别提交的 ZIP 在 `提交包`。每个包内的「作品」均有自己的运行入口。

报告封面的学院、专业、姓名、学号留白。提交时填写个人信息，重新导出对应 PDF，并将报告和压缩包文件名中的“学号_姓名”替换为个人信息。
