在 Windows 启动完整网站

  1. 解压。准备 Python 3.10 或更新版本，解压完整网站，打开含有 server.py 的文件夹。
  2. 启动。双击「启动小溟.cmd」，保留启动窗口。浏览器会自动打开；也可复制窗口中显示的本机网址。
  3. 选择模式。本地规则无需密钥。要让 DeepSeek 回应，先在首页输入自己的 API 密钥并开启联网授权。
关掉窗口后，怎样继续？

从同一目录重新运行启动程序，可以继续此前保存的聊天和游戏。

怎样开始聊天

在完整网站首页点「开始对话」，选择运行方式。在「写给小溟」里写下今天想分享的事，然后发送。

本地规则
按照问候、心情、游戏等话题选择预设回复，断开外部网络也可使用。
DeepSeek 联网
模型结合最近几轮联网对话作答。发送失败时检查网络，在原消息上点「重试发送」。

怎样进入游戏

国际象棋

从游戏间进入棋桌，选择执白或执黑。点选己方棋子，再点合法目标格。棋谱会记录双方走法；将死对方就能取胜。

谁是卧底

你与三位玩家各获一个秘密词。三人同词，一人异词。轮流给线索，避开词语本身，再讨论、投票。平票时辩护复投。平民要找出卧底，卧底则要留到只剩两人。
