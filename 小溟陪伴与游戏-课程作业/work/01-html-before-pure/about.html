启动与连接

  1. 解压完整网站

    准备装有 Python 3.10 或更高版本的 Windows 电脑。解压课程包，打开含有 server.py 的网站目录。

  2. 打开启动程序

    双击 启动小溟.cmd，保留打开的命令窗口。浏览器会自动打开网站；也可以把窗口里的本机网址复制到地址栏。

  3. 选择运行方式

    选「本地规则」可直接聊天或试玩。要使用 DeepSeek，在首页填写自己的 API 密钥，勾选联网授权，再保存设置。

关闭命令窗口即可停止服务。在同一目录重新启动，可以继续此前保存的对话和棋局。

与小溟聊天

在完整网站点「开始对话」，选择运行方式，在「写给小溟」里输入想说的话。比如，告诉它你为哪场活动紧张，或者最近完成了哪件开心的小事。

本地规则
按问候、心情和游戏等话题给出预设回应。断开外部网络也能使用。
DeepSeek 联网
模型结合最近几轮对话回答。等待结束后可以接着聊，遇到请求失败可在原消息上点「重试发送」。

两款游戏的玩法

国际象棋

从「游戏间」进入棋桌，选执白先行或执黑应战。轮到你时，先选己方棋子，再点有标记的目标格。棋谱会记录双方走法。

将军且对手无法解围时获胜。独立的「一步将死」练习也可以离线打开。

谁是卧底

四人各获一个秘密词，其中三人同词、一人异词。轮流描述，避开词语本身。读完公开线索、讨论后，投给你怀疑的玩家。

平票时进入辩护与复投。找出卧底则平民获胜；只剩两人时，卧底获胜。
