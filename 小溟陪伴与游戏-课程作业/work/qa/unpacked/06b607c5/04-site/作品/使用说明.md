# 小溟陪伴与游戏

将整个文件夹解压。Windows 已安装 Python 3.10 或更新版本时，双击「启动小溟.cmd」，浏览器会打开 http://127.0.0.1:8768/ 。关闭启动窗口即可停止服务。可从终端运行 `python -B server.py --port 8768 --no-browser` 并手动打开首页。象棋规则依赖已随包附带，无需 pip 安装。

首页的连接设置可使用 DeepSeek 密钥和明确的云端授权。支持原 EcoCompanion 的本机 DPAPI 配置（仅读取），新设置仅保存于此站点 .runtime，Windows 使用当前账户的 DPAPI 加密，其他平台的密钥仅在当前进程内生效。浏览器只接收配置状态。联网聊天会向 DeepSeek 提交最近六轮同模式对话，联网游戏只提交当前玩家可知的信息。云端调用按服务商计费。

在离线体验中，小溟按本地短句模板回应，国际象棋由本地规则对手走子，「谁是卧底」由词条线索和规则玩家参与。页面标明模式，网络失败可在原回合重试。游戏与对话自动保存在 .runtime；解压到可写目录，复制或提交作业时排除此目录。独立验收可用 `python -B server.py --port 8770 --isolated --profile check --no-browser`，与个人资料分开。此网页为一般陪伴与娱乐用途。

国际象棋与谁是卧底的核心规则来自原 EcoCompanion；python-chess 1.11.2 的源代码与 GPL 许可见 vendor。角色溟月由上善无形创作，素材取自 dsh-pet 社区及原项目。完整来源见 public/assets/ATTRIBUTION.md。鱼形角色图沿用原项目 web/public/games。
