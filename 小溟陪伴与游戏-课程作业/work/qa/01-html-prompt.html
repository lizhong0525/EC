作业一 · 小溟的房间（纯 HTML 修订稿） · 实际任务书

我要做一个第一次接触小溟的人也能读懂的陪伴网站。请只交付可离线双击的 index.html 和 about.html 两个文件。首页展示原作中的小溟、角色介绍、一段明确标为示例的对话，以及聊天和游戏两个指南入口。手册按 Windows 启动、联网与离线、聊天、两款游戏、素材署名组织，每一节都要能跳回首页对应入口。

请只使用原生语义 HTML。使用标题、导航地标、列表、picture、details 和 summary。把优化后的 WebP 插画内嵌到文件，使用 picture 适应窄屏；可用原版小溟和环境组成独立横幅，正文与导航保留为可选择的文字。不要引入 CSS、脚本、SVG、事件属性或外部运行依赖。

请以真实浏览器测试 320 像素与桌面布局、断网、折叠说明和两条往返路径，尤其是 #chat-guide 与 #games-guide。保留初稿证据，在修复后重新拍摄首页、手册和对应代码。

本次取代前版对素材文件的交付方式；旧提示词已存入工作备份。
