# AstrBot 风格消息渠道兼容版

日期：2026-10-27。本版没有嵌入 AstrBot 或 whale_gril 源码，也没有引入
NapCat。参考 AstrBot 的“统一事件 -> 渠道适配 -> 会话/模型 -> 回复”思路，
保留本项目已有的本地规则、Qwen 证据提取、Jev 建议和输出审查。

## 最短 QQ 流程

1. 在“设置 / 对话服务”保存 DeepSeek Key、人格与云端传输许可。未启用云端时
   仍可本地回复，不会伪称 DeepSeek 已连接。
2. 在“消息渠道”填写 QQ 开放平台机器人的 AppID 和 AppSecret，启用 QQ 并保存。
3. 点击“启动已保存配置”。预检只检查 AccessToken 和 Gateway；实际私聊收发
   仍需在 QQ 沙箱中验证 C2C 权限、沙箱用户、发布状态与被动回复时限。

参考视频 BV1x2Jq6NEbT 的公开简介采用官方 QQ AppID/AppSecret 路线，本实现
也只采用该路线。没有将 DeepSeek Key 放到 NapCat，也没有要求部署两个 AI 配置。

## 微信公众号

原有官方公众号明文 XML 回调保留。Token、AppID、AppSecret 与个人微信桥接
完全分开，公网仍需受管理的 HTTPS 反向代理。详细协议见
`MESSAGING_INTEGRATION.md`。

## 个人微信隔离测试桥接

whale_gril 的本地 JSON 网关格式提供参考；本实现只接受一个小兼容子集：

```json
{
  "chat_id": "wxid_test_friend",
  "chat_type": "private",
  "user_id": "wxid_test_friend",
  "text": "你好",
  "msg_id": "stable-local-id"
}
```

入口为 `POST http://127.0.0.1:8765/webhook/wechat`，请求头为
`x-bot-token: <独立随机 Token>`。兼容 `content/chatId/senderId/msgId` 别名。
缺少稳定 ID、非白名单会话、机器人自身消息、非文本消息都会被忽略。
首次仍需回复“同意”；模型、人格和独立渠道会话沿用统一处理器。

1. 准备专用测试微信和测试好友，不使用日常账号。明确当前自动化方案不是
   官方个人微信 API，可能有账号条款、版本、焦点和误发风险。
2. 在设置页确认测试边界，点击“读取账号与全部好友”。应用自动识别当前账号的
   内部 ID；按备注或昵称搜索并勾选测试好友，无需手动查询或填写 wxid。
   更换账号会清空旧好友白名单，选择完成后启用并保存。
   Token 留空会自动生成，以 DPAPI 绑定当前 Windows 用户，无需复制到脚本。
3. 执行 `.\Install-WeChatTestBridge.ps1`，显式安装固定版本
   `wechatauto-replica==1.2.7.0`。这不是桌面应用的默认依赖。
4. 保持消息网关运行，点击“启动微信桥接”，或执行
   `.\Start-WeChatTestBridge.ps1`。独立进程读取本地数据库并通过 UI 发送；
   不会随应用启动，退出桌宠会停止由设置页创建的桥接进程。
5. 桥接脚本核对账号，收发均限制白名单，发送后回读数据库。只有实际测试
   成功才可记录“微信真实收发通过”。

“读取账号与好友”使用独立、只读的发现进程，不启动消息监听或窗口自动化。
它只向本机设置页返回账号/好友的内部 ID、备注和昵称，不返回消息内容或密钥；
默认完整列出联系人，不设 60 人截断；搜索按备注、昵称或内部 ID 匹配数据库
返回的候选。刷新全部好友会清除旧搜索词，空结果保留可见提示。
首次使用需要先安装可选依赖。桥接运行期间需先停止桥接再重新读取。
缺少组件时，设置页会在读取失败后提供“安装桥接组件”，经确认后调用同一个
固定版本安装脚本，无需回到命令行；安装完成后再点击“读取账号与好友”。
安装脚本只安装并验证依赖可导入，不再提前要求账号与好友配置。首次安装
`winsdk` 可能需要本地构建数分钟，页面会显示实际阶段，请保持应用开启。

当前桥接只支持私聊。参考库的监听记录没有可靠的显式 @ 字段，本版不通过
昵称猜测触发，群聊保持关闭。主动搭话、朋友圈、媒体识别和自动多气泡
均不在接入范围。完整 whale_gril 脚本功能远多于本适配器，不能混为一谈。

## 状态与上线边界

设置页“消息网关运行中”只说明本地进程已启动，不表示 DeepSeek 已生成、
QQ 权限获批或微信窗口收发成功。桥接脚本缺依赖时 `--check` 会明确报告，
不会尝试访问微信。个人微信目前未完成真实账号验证。
