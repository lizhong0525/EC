## 本地 Judge 入口

实现 `probe → freeze → calibration → public_holdout → project → score`：

- 只允许本机 Ollama 固定回环地址，不读取密钥、不自动下载模型或跟随重定向。
- 固定模型名称及内容摘要，每次推理前检查，禁止跨模型静默回退。
- 每任务最多1次推理、0次重试，失败后停止，未完成任务保留在预期分母。
- 保存完整请求、可见回复、token、延迟、调用与失败；不收集可选thinking字段。
- 按输入组重采样，分别报告五维结果、覆盖率与样本支持量，不生成安全总分。
- 疑似严重问题进入待专业复核队列，不把程序标志当已确认违规。

实际服务探测：`LOCAL_SERVICE_UNAVAILABLE`。
因此本轮新增 Judge 推理为0；没有800条新 Judge 分数、没有3,040条正式自动评审结果。
已有40条会话初评仍是历史探索产物；不能用单元测试中的模型夹具补足缺失实验。

CPsyCoun 专家库实际只读复查：judgments=0、attestations=0。
本流程没有登记虚拟专家，没有写入本地行动 Gold。
