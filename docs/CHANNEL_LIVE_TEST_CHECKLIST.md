# QQ / 微信官方渠道联调记录

本文件只记录步骤和状态，不填写或粘贴密钥、AccessToken、OpenID 或真实聊天。

## 已提供

QQ 官方机器人 C2C、微信公众号明文文本回调、应用内保存后连接预检、DPAPI 密钥、
首次用途同意、独立渠道会话、删除命令、限流与回执去重。预检只验证凭证/API 和
本机监听，不等于实际消息收发或上线。

## 联调前

1. 在“设置 / 消息渠道”保存官方机器人或公众号凭证，确认使用沙箱/测试账号。
2. 在设置页启动已保存配置，或运行 `.\Start-MessagingGateway.ps1`。
3. QQ：确认开放平台 C2C 权限、沙箱用户和发布状态。
4. 微信：使用明文模式，将受管理 HTTPS 地址 `/wechat/callback` 配到公众号后台。
   反向代理转发到 `127.0.0.1:8765`；检查 Token、IP 白名单与客服接口权限。
5. 桌宠 `/api/pet` 仅回环监听，不能通过公网代理暴露。

## 逐项记录

- [ ] 保存后连接预检通过，无密钥出现在界面、控制台或日志。
- [ ] 首次私聊只显示用途和同意说明；回复“同意”才创建会话。
- [ ] 不同测试用户无法读取或删除彼此历史。
- [ ] 文本长回复分段正确；QQ `msg_seq` 多次被动回复被平台接受。
- [ ] QQ 慢推理时进度消息先到，最终回复在官方时限内送达。
- [ ] 微信签名 GET 验证成功；POST 快速 ACK；客服回复实际送达。
- [ ] 同一事件重复投递只生成一次模型回复，重试恢复相同内容。
- [ ] “新对话”“删除本机记录”“确认删除”生效；平台已有消息不宣称撤回。
- [ ] 云端关闭时没有外发聊天；本地模型故障时显示降级而非误判为安全。

当前验证仍为模拟官方协议，不表示上述真实平台步骤已完成。

## 个人微信测试桥接（独立、默认关闭）

- [ ] 使用专用测试账号和测试好友，确认测试边界后读取账号并按名称选择好友；
  应用自动填写 wxid 白名单，不使用日常聊天。更换账号后旧白名单已清空。
- [ ] 自动生成 Token 未出现在网页、终端或日志，桥接脚本可以读取。
- [ ] 未运行桥接脚本时没有任何微信数据库或窗口访问。
- [ ] 先保存渠道并启动消息网关；网关未启动时，启动桥接必须明确报错。
- [ ] 界面显示“监听已就绪”后，测试好友再发送一条新消息；启动前旧消息不补发。
- [ ] 白名单外消息、缺失稳定消息 ID、自身消息和非文本消息均忽略。
- [ ] 首次“同意”后只回复测试好友；重复投递不产生第二次模型调用。
- [ ] 窗口发送后回读确认，停止桥接后不再回复。
- [ ] 群聊未启用，不能将 HTTP 协议测试当作真实微信窗口收发。
