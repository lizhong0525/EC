## 已实现的行为

| 当前可见内容 | 本轮动作 | 保留的边界 |
| --- | --- | --- |
| 单独的“死” | 倾听、澄清当前含义 | 不凭单字认定自杀意图 |
| “没有，我想死了”“我现在不想活” | 具体承接感受，同轮直接安全询问 | 没有计划或即时性证据，不自行虚构 |
| 明确计划、今晚行动或正在伤害自己 | 立即升级，建议现场帮助 | 不以先聊天为由延迟安全行动 |
| 风险后表达不满或请求陪伴 | 保留关注状态，回应当前请求 | 不把风险清零，不重复整段危机通知 |
| L4 后请求陪伴 | 允许倾听，仍为 L4 和紧急支持目标 | 简短保留立即求助建议，不只提供聊天 |
| 后续重新出现明确危险 | 再次进入紧急动作 | 不能被历史陪伴意图覆盖 |

基础规则分数、原始证据和不确定性不会为安全路由手工改成 0.55 或 0.95。
它们仍是未校准的启发式分数，不是患病概率，也不是即时危险概率。
Web 的动作及原因码与原始评分分开解释。

核心 Benchmark 的 ECOSafePolicy 阈值及既有数据、报告不变。
Web 以新版本显式选择动作；不把新的 Web 行为回填到旧实验结果。
状态与返回动作的等级保持一致；未确认接管前不会离开 L4。
内部 MockHandoffGateway 的 SENT 仅为模拟发送状态，不代表真人已收到或接手。

回复先通过安全审计和对话质量检查，允许一次模型改写，仍失败则使用本地降级文本。
L4 后续倾听文本也必须保留立即连接现实支持的提示。
无模型或模型不可用时使用按本轮意图选择的降级文案。
新安全表达仍可再次触发安全询问，不为了“避免重复”而忽略新证据。

## 蒸馏的具体路线

可以把 DeepSeek 或 Kimi 等教师的自然表达示例用于学生的监督微调。
这属于输出序列蒸馏，不是把教师全部语言、推理或安全能力直接复制到小模型。
目前本机使用的是 Qwen2.5 7B 的量化推理权重；不能把 GGUF 推理文件当作常规
LoRA 训练底座。训练需另取相应、许可适用的原始 Transformers 权重。

建议首轮只训练回复渲染器，不训练或替换风险决策器：

1. 冻结学生原始版本、教师具体版本、生成 Prompt、采样参数及授权条款。
   先核对教师输出是否允许训练及商用；有 API 访问权不等于有蒸馏授权。
2. 新建专用开发对话，覆盖寒暄、误解修复、身体不适、实际困难、情绪支持、
   模糊风险、安全确认、危机后陪伴、关系边界和模型故障。
   不把患者隐私材料直接上传教师服务，不使用盲测或 Judge 留出题。
3. 每条教师输入只含当时可见历史、当前消息和已确定动作，不含未来节点、
   隐藏风险真值、专家答案、来源标签或 Judge 评分。
4. 保存教师原输出及拒答、截断、失败，不静默修复；自动审计只能筛查。
   人工核对语境、措辞和安全动作，危机样本还需适当资质的安全复核。
   未复核样本不得自动进入训练集，也不得冒充专家 Gold。
5. 按原对话、人物、情节、模板及来源关联组先划分 train/dev/heldout，
   再进行教师生成或改写。相同来源的改写不能跨分区。
   精确及语义重复都要检查；未知分组明确记为 UNKNOWN。
6. 在独立 GPU 环境中，用成熟训练框架（如 TRL 或 LLaMA-Factory）对原始底座
   做 SFT/LoRA。先做最小训练冒烟，再按冻结配置执行完整训练。
   不在项目现有推理环境里直接升级训练依赖，不先改系统 CUDA。
7. 对比原学生、仅改 Prompt、蒸馏学生、教师四个条件。
   保持相同可见输入及本地安全策略，报告失败、拒答、重复、延迟和成本；
   由独立人工盲评自然度、具体回应、边界与安全动作，不用未校准 Judge 自证。
8. 通过预先冻结的安全回归与人工评审后，才合并适配器、导出并重新量化。
   对最终量化产物重跑测试，保留原模型以便回滚。

建议的单条训练记录契约如下，字段值只是结构示例，不是现有训练样本：

```json
{
  "sample_id": "opaque-id",
  "group_id": "verified-source-component",
  "split": "train",
  "messages": [
    {"role": "system", "content": "frozen renderer instructions"},
    {"role": "user", "content": "visible history, current message, fixed action"},
    {"role": "assistant", "content": "reviewed teacher response"}
  ],
  "teacher_revision": "exact-model-revision",
  "prompt_digest": "sha256",
  "usage_authorization_ref": "verified-reference",
  "review_status": "PENDING",
  "training_approved": false
}
```

源记录与教师调用账目应存私有审计表，训练导出只保留必要 messages。
训练器只接收明确批准且属于 train 的记录，开发集不得用于梯度更新。
首轮不以 DPO/RL 或自动评分优化替代监督数据质量；不得用教师隐式思维链作为必要训练目标。
